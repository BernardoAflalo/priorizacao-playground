# Simulador de Priorização de Projetos

Material complementar da aula de **Priorização de Projetos** (Modelagem Preditiva — FGV).

Acesse: https://bernardoaflalo.github.io/priorizacao-playground/

- **Matriz RICE** — Alcance × Impacto × Confiança / Esforço, com modo comitê (votação entre stakeholders)
- **Valor Presente Líquido** — fluxo de caixa mês a mês, TIR, payback descontado (exemplo da aula: VPL = R$ 28.974)
- **Conhecido × Desconhecido** — valuation de uma iniciativa de churn e o peso das premissas
- **Portfólio com orçamento** — seleção ótima vs. regras simples
